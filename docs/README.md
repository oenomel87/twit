# twit 문서

에이전트 간 비동기 협업 중계 시스템 twit의 설계 문서를 보관한다.

현재 설계 방향은 **SQLite + CLI 기반 v2 메일 인박스**다. 구현은 완료되어 있다(`npm install && npm run build && npm link`). 긴 문서·문서 폴더는 본문에 절대 경로와 읽을 범위를 적어 전달한다. 01·02 문서는 이전 작업 관리 방식의 참고 자료로 보존하며, v2에 자동 적용하지 않는다.

| [v2 구현 로그](./06-implementation-log.md) | 기록 | 단계별 진행 기록, 구현 중 특이 사항, 설계 밖 구현 결정, 검증 기록 |
| [v2 메일 인박스 기능 설계](./03-v2-mail-inbox-design.md) | 유효 | 현재 방향. 메시지 전송·수신함·읽기·답장·대화 조회·보관, 긴 문서 전달 가이드 |
